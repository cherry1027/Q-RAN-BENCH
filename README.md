# Q-RAN Bench

**Quantum-Classical RAN Workload Benchmark**

Q-RAN Bench is a small interactive research prototype that demonstrates how hybrid quantum-classical architectures could be evaluated for telecom Radio Access Network (RAN) workloads.

🔗 **Live demo:** https://q-ran-bench.charanvaranasi44.workers.dev

## Features

- Interactive hybrid RAN architecture visualization
- Classical CPU/GPU versus quantum QPU comparison
- Three synthetic RAN use cases:
  - Resource Allocation
  - Traffic Optimization
  - Anomaly Detection
- Adjustable dataset size, problem size, noise level, qubit count, circuit depth, shots, and interconnect latency
- Simulated latency, solution-quality, overhead, and resource metrics
- End-to-end latency breakdown chart
- Hardware comparison for:
  - Superconducting QPUs
  - Trapped Ion QPUs
  - Neutral Atom QPUs
- Synthetic hardware suitability scores
- Hypothetical classical–quantum break-even analysis
- Automatically generated execution strategy and bottleneck recommendation
- Responsive technical-dashboard interface
